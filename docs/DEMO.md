# Демонстрация Freedom CQA — 4:50, без новых Groq-вызовов

Это **техническая репетиция на собственной синтетике и fake ML**. Она показывает
UI, Java scoring, evidence, версионирование и review, но не качество LLM и не обработку
CONTROL. Исторический live E2E на prompt v3 — отдельное свидетельство в plan.json.

## Подготовка вне пяти минут

1. Выполнить build из [Quick Start](../README.md), затем
   `python3 -B server/src/test/python/batch_smoke.py --serve`.
   Harness сам поднимает Java/fake HTTP ML, temporary SQLite, три разрешённых RU/KZ/EN
   public fixtures и три сохранённые model-origin оценки. Он не запускает Groq.
2. Открыть напечатанный адрес workspace (без `/__tests/`). Выбрать
   `synthetic-local / v1` в верхнем selector. Не запускать browser regression на этой
   же базе перед репетицией: он специально меняет rubric/историю и перезапускает JVM.
3. Выбрать `SYNTHETIC:kz_public_na`; заранее найти его результат. Текст короткий,
   четыре учебных критерия. Это **не** полный официальный seed из восьми критериев.
4. Подготовить окна «Диалоги», «Результаты и review», «Чек-листы». Не открывать `.env`,
   private DB, Organizer URL или реальные datasets. Audio не загружать.
5. При необходимости прогнать полную автоматическую репетицию на **отдельном свежем**
   `auto_smoke.py --serve`, открыть напечатанный T14 browser URL и нажать Run. Семь
   сценариев проверяют model appeal, CAS, flag, manual v2 и restart.

## Ход показа

| Время | Действие | Что сказать / проверить |
|---|---|---|
| 0:00–0:40 | Диалоги → KZ, открыть kz_public_na. Показать IDs, роли и timestamps; кратко переключить RU/EN. | «Это собственная синтетика; сейчас backend использует fake ML. Исходные сообщения и роли сохранены; приветствие бота не засчитывается оператору». |
| 0:40–1:50 | Результаты → сохранённая v1 оценка этого диалога. Нажать evidence-ссылку у LOCAL_IDENTITY и LOCAL_CLARITY. | Original=final=100. IDENTITY=N/A исключает вес25: применимый вес75. Цитата переносит к точному message_id. Flags отдельны от численного штрафа. Итог считает Java, не модель. |
| 1:50–3:05 | Создать appeal LOCAL_CLARITY. В review выбрать change, уровень0, оставить дословное evidence, написать reason «Учебная проверка пересчёта; не новая разметка качества», сохранить. | «Это намеренное учебное изменение для проверки механизма». Original остаётся100, final=33,33: 100×25/75. Revision и решение видны в истории. При409 перечитать результат и осознанно пересмотреть draft; не кликать retry вслепую. |
| 3:05–4:10 | Чек-листы → synthetic-local/v1 → «Добавить критерий»: ID DEMO_EXTRA, название «Порядок ответа», instruction «Проверить последовательность ответа по цитате», binary, weight25, allow_na=false; сохранить новую версию. | Новая v2 содержит произвольный ID без изменения кода. Вернуться к сохранённой оценке v1: она осталась v1 с прежними original/final. Ручной composer v2 показывает дополнительный ответ. |
| 4:10–4:40 | Массовая AI-оценка: снова выбрать **v1**, группу SYNTHETIC, «Зафиксировать batch». Показать зафиксированные IDs/version и действия run/pause/status. | «Один запрос за раз. После reload только сверка ledger, затем явный resume. Неизвестный исход никогда не повторяется автоматически». В этой репетиции запуск разрешён только через fake ML, не обычный provider. |
| 4:40–4:50 | Кратко назвать ограничения. | «Новые критерии работают вручную. Новый AI-сценарий, реальные данные и live v4 требуют согласования; без разрешения система показывает ошибку, а не выдуманный результат». |

Сохранение всех пяти ручных ответов v2, confirm/change critical flag, конфликт409 и restart
проверяются семью T14 browser-сценариями и Java tests; не обещайте уместить заполнение
всех полей дополнительно в эти 4:50. Для ручного расширения используйте T14 walkthrough
в [server/README.md](../server/README.md).

Если сервис/интернет недоступен, показывайте сохранённую синтетическую оценку и честную
ошибку. Не меняйте policy, не включайте реальный provider и не выдавайте stub diagnostics
за стоимость/качество Groq. Enter в терминале harness останавливает только его процессы
и удаляет его временную базу. Не закрывайте обычную пользовательскую Java/ML сессию.
